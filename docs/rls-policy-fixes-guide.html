Issue 1: organization_id Missing Error

Problem: RLS policies reference organization_id column that doesn't exist in scope, causing errors or overly permissive policies.

Problematic Code Pattern

Multiple policies contain broken patterns where organization_id was supposed to be referenced but was commented out with FIXME notes: 

-- From 20260127000002_consolidate_permissive_policies.sql
CREATE POLICY "families_select_policy" ON families
  FOR SELECT
  USING (
    -- Parents can view their own family
    EXISTS (
      SELECT 1 FROM users 
      WHERE users.id = (select auth.uid()) 
      AND users.family_id = families.id
    )
    -- Coaches can view families
    OR EXISTS (
      SELECT 1 FROM users 
      WHERE users.id = (select auth.uid())  
      -- AND user_has_org_role((select auth.uid()), organization_id, 'coach') 
      -- FIXME: organization_id not in scope
    )
    -- Admins can view families
    OR is_platform_admin((select auth.uid()))
  );

Why This Is Broken

  • The EXISTS clause now only checks if the user exists (always true for authenticated users)
  • The coach role check was removed, making the policy overly permissive
  • There are 12+ occurrences of this pattern across multiple tables

Issue 2: Can't Insert First Organization Member

Problem: When creating a brand new organization, no one can insert the first member because the INSERT policy requires being an org admin, but no admins exist yet (chicken-and-egg problem).

Current Policy

-- From 20260127000001_fix_auth_rls_initplan.sql
CREATE POLICY "Org admins can manage org memberships" ON organization_members
  FOR INSERT
  WITH CHECK (user_is_org_admin((select auth.uid()), org_id));

Why This Fails

  1. New organization is created (empty, no members)
  2. User tries to insert first member (themselves as org_admin)
  3. Policy checks: user_is_org_admin(auth.uid(), org_id)
  4. Function returns false because no membership exists yet
  5. INSERT is rejected ❌

Solution

Add a bootstrap policy that allows inserting the first member when the organization is empty: 

CREATE POLICY "Allow bootstrap member insert" ON organization_members
  FOR INSERT
  WITH CHECK (
    -- Platform admins can always insert
    is_platform_admin((select auth.uid()))
    -- Org admins can insert into their org
    OR user_is_org_admin((select auth.uid()), org_id)
    -- Allow insert if org has no members (bootstrap case)
    OR NOT EXISTS (
      SELECT 1 FROM organization_members om2 
      WHERE om2.org_id = organization_members.org_id
    )
  );
Note: You mentioned adding 2 new policies for this. Make sure they don't conflict with existing policies. Consider consolidating them into a single policy with OR conditions.

Recommended Fixes

Fix 1: Correct Broken Coach Policies

For tables that need coach access checks, join through teams or organization_members to get the org_id: 

-- Example: Fix families_select_policy
DROP POLICY IF EXISTS "families_select_policy" ON families;

CREATE POLICY "families_select_policy" ON families
  FOR SELECT
  USING (
    -- Parents can view their own family
    EXISTS (
      SELECT 1 FROM users 
      WHERE users.id = (select auth.uid()) 
      AND users.family_id = families.id
    )
    -- Coaches can view families in their org
    OR EXISTS (
      SELECT 1 FROM athletes a
      JOIN team_memberships tm ON tm.athlete_id = a.id
      JOIN teams t ON t.id = tm.team_id
      WHERE a.family_id = families.id
      AND user_has_any_org_roles((select auth.uid()), t.org_id, ARRAY['coach', 'org_admin']::org_member_role[])
    )
    -- Admins can view families
    OR is_platform_admin((select auth.uid()))
  );

Fix 2: Add Bootstrap Policy for organization_members

-- Drop existing restrictive INSERT policy
DROP POLICY IF EXISTS "Org admins can manage org memberships" ON organization_members;

-- Create consolidated INSERT policy with bootstrap support
CREATE POLICY "org_members_insert_policy" ON organization_members
  FOR INSERT
  WITH CHECK (
    -- Platform admins can always insert
    is_platform_admin((select auth.uid()))
    -- Org admins can insert into their org
    OR user_is_org_admin((select auth.uid()), org_id)
    -- Allow insert if org has no members (bootstrap case)
    OR NOT EXISTS (
      SELECT 1 FROM organization_members om2 
      WHERE om2.org_id = organization_members.org_id
    )
  );
